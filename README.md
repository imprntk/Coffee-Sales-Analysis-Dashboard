☕ Coffee Sales Analysis Dashboard

#📊 Project Overview

This project presents an interactive Coffee Sales Dashboard built using Microsoft Excel to analyze sales performance from 2019 to 2022.

The dashboard provides clear insights into customer behavior, product performance, and regional sales trends, helping businesses make data-driven decisions.

#🚀 Key Features
#📈 Sales Performance Analysis
Multi-line chart comparing sales across coffee types:
Arabica, Excelsa, Liberica, Robusta
Identify seasonal trends and peak sales periods

#🌍 Geographical Insights
Sales comparison across:
United States, Ireland, United Kingdom
Highlights market dominance and regional demand

#👥 Customer Insights
Identifies Top 5 Customers based on total spending
Helps target high-value customers

#🎛️ Interactive Filters
Dynamic slicers for better analysis:
Roast Type: Light, Medium, Dark
Size: 0.2kg, 0.5kg, 1.0kg, 2.5kg
Loyalty Card Status

#🗓️ Time-Based Analysis
Timeline slicer for year-wise and month-wise filtering
Enables deep dive into specific time periods

#🛠️ Tools & Technologies
Microsoft Excel
Pivot Tables & Pivot Charts
Slicers & Timeline Filters
Power Query (for data cleaning & transformation)

#📈 Key Insights
📊 Sales Trends: Strong monthly fluctuations reveal seasonal demand patterns
🌍 Top Market: United States leads significantly in total sales
☕ Product Performance: Arabica and Robusta show peak demand during high-sales periods
🎯 Customer Focus: A small group of customers contributes significantly to revenue
